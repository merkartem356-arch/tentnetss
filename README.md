# Tent Nets — Forge 1.21.1

Натяжные сети, которые ставятся под любым углом по опорным точкам.

- **Антидроновая сеть** (`tentnets:anti_drone_net`) — полупрозрачная сетка. Дроны и сбросы/снаряды взрываются на ней, не долетая до земли. Пули пролетают сквозь.
- **Маскировочная сеть** (`tentnets:mask_net`) — непрозрачный камуфляж. Закрывает всё под собой от взгляда сверху и скрывает ники игроков, которые под ней.

## Как ставить

| Действие | Результат |
|---|---|
| ПКМ по блоку | опорная точка в месте клика (до 8) |
| Shift + ПКМ | натянуть сеть между точками (минимум 3) |
| ПКМ в воздух | отменить последнюю точку |
| Shift + ПКМ в воздух, когда точек нет | снять сеть, на которую смотришь (предмет возвращается) |

Пока выбраны точки, они подсвечиваются частицами, а контур будущей сети — линиями. Точки лежат не обязательно в одной плоскости: мод строит плоскость наилучшего приближения и берёт выпуклую оболочку точек. Максимальное расстояние до первой точки — 48 блоков.

## Что считается дроном/снарядом (антидроновая сеть)

Решает `NetRules.classify`, по порядку:

1. **Теги сущностей** `data/tentnets/tags/entity_type/`:
   - `passthrough.json` — пролетает сквозь (стрелы, трезубец);
   - `explode.json` — взрывается на сетке;
   - `catch.json` — застревает и исчезает.
2. **Эвристика по id сущности**: `bullet`, `cartridge`, `slug` → пролетает; `drone`, `fpv`, `kamikaze`, `shahed`, `bomb`, `grenade`, `missile`, `rocket`, `shell`, `mortar`, `torpedo` → взрывается.
3. Всё, что наследует `AbstractArrow` — пролетает; TNT и огненные шары — взрываются; прочие `Projectile` — застревают.

Чтобы подключить сущности из другого мода, просто добавьте их id в теги. Для необязательных модов используйте `{ "id": "modid:drone", "required": false }`. Датапаком можно переопределить без пересборки.

Взрыв на сетке **не ломает блоки** (`ExplosionInteraction.NONE`), но бьёт существ рядом. Сеть выдерживает 12 попаданий (`NetEntity.MAX_HITS`).

## Сборка

Проект в стиле Forge MDK 1.21.1 (ForgeGradle 6, Java 21).

```
gradlew build        # jar окажется в build/libs
gradlew runClient    # запуск для теста
```

Если у вас уже есть свой MDK, скопируйте `src/` в него и приведите `mod_id=tentnets` и `mod_group_id=com.tentnets` в `gradle.properties`. Версия Forge в `gradle.properties` (`forge_version`) — поставьте актуальную 52.x.

## Заметки

- Форма сети синхронизируется строкой через `SynchedEntityData`, отдельных сетевых пакетов нет.
- Перехват работает по отрезку движения за тик (от `xo/yo/zo` до текущей позиции), поэтому быстрые объекты не «простреливают» сеть. Ограничение: до ~6 блоков за тик (`SCAN_RANGE`).
- Скрытие ников — только клиентская отрисовка (`RenderNameTagEvent`), на сервере ники по-прежнему существуют.
